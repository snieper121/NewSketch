## Что это такое

**Ai IDE** — полноценная мобильная IDE для создания Android-приложений на Jetpack Compose. Она работает целиком на устройстве: от визуального проектирования интерфейса до компиляции и установки готового APK. Не нужен компьютер, Android Studio, SDK Manager или эмулятор.

Приложение ориентировано на начинающих разработчиков, хобби-программистов, преподавателей и студентов, а также на быстрое прототипирование идей. Создание UI происходит визуально — через палитру виджетов и drag-and-drop на канвасе. Логика приложения задаётся через декларативные события и состояния. AI-ассистент помогает сгенерировать экраны, исправить ошибки и объяснить код.

Генерируемые проекты используют современный стек: **Jetpack Compose + Material3 + Kotlin Coroutines + Navigation Compose**. Никакого XML, никакого View system. Результат можно сразу установить на телефон или экспортировать как стандартный Gradle-проект и открыть в Android Studio.

## Возможности

| Фича | Описание |
|------|----------|
| **Визуальный редактор** | Drag-and-drop виджеты Compose на канвас, настройка свойств в панели |
| **AI-ассистент** | Генерация экранов, виджетов и логики через чат с контекстом проекта |
| **On-device сборка** | Компиляция Kotlin + ресурсы + DEX + подпись APK без Gradle и без root |
| **Material3 + Dynamic Color** | Современный дизайн, тёмная тема, адаптивная цветовая схема |

| **Состояния и события** | Переменные экрана, обработчики onClick, навигация, snackbar, диалоги |
| **Ресурсы** | Цвета, строки, размеры, изображения — визуальный менеджер |
| **Экспорт** | Сохранение проекта как Gradle-проект (открывается в Android Studio) |
| **SAF импорт/экспорт** | Работа с файлами через стандартный Android picker, без dangerous permissions |

## Как это работает

### Архитектура (high-level)

```
┌─────────────────────────────────────────────────────────────┐
│                      UI Layer (Compose)                     │
│   Projects · Editor · Screen Manager · Resources · Build    │
├─────────────────────────────────────────────────────────────┤
│                  Presentation (ViewModel + StateFlow)       │
├─────────────────────────────────────────────────────────────┤
│                     Domain (JSON model)                     │
│        project.json · screen.json · resources.json          │
├─────────────────────────────────────────────────────────────┤
│                      Data Layer                             │
│   Room DB · FileSystem · Ktor · DataStore · AI Providers    │
├─────────────────────────────────────────────────────────────┤
│                      Build Layer                            │
│   ToolchainManager · kotlinc · ecj · aapt2 · d8 · sign      │
└─────────────────────────────────────────────────────────────┘
```

### Парадигма разработки

1. **JSON — source of truth.** Визуальный редактор работает с JSON-моделью проекта. Kotlin-код генерируется автоматически через KotlinPoet и никогда не редактируется вручную (кроме специального `custom/` блока).
2. **On-device build.** Компилятор Kotlin, Eclipse JDT (ecj), aapt2, d8/R8 и apksigner запускаются прямо на устройстве через DexClassLoader. Toolchain (~130 MB) скачивается при первой сборке и верифицируется по SHA-256.
3. **AI-first.** AI работает на уровне JSON-патчей: генерирует структуру экранов, виджетов и событий, а не сырой код. Это гарантирует валидность и безопасность.

## Экраны приложения

| Экран | Назначение |
|-------|------------|
| **Home / Projects** | Список проектов, создание нового из шаблона, импорт/экспорт |
| **Editor** | Визуальный редактор: DesignCanvas, палитра виджетов, дерево файлов |

| **Resource Manager** | Управление цветами, строками, размерами, изображениями |
| **State & Logic** | Переменные экрана, события, обработчики, выражения |

| **Project Settings** | Package name, minSdk, permissions, зависимости, manifest |

## Инструкция по использованию

### 1. Создание проекта

1. Откройте приложение → нажмите **«+ Новый проект»**
2. Введите имя приложения и package name (например, `com.example.myapp`)
3. Выберите шаблон (пустой или с примером)

### 2. Редактирование UI

1. Перейдите в **Editor**
2. В **палитре виджетов** выберите нужный элемент (Text, Button, Column, Card и др.)
3. Перетащите на **DesignCanvas** или нажмите для добавления
4. Выделите виджет — откроется **Property Editor** (bottom sheet)
5. Настройте текст, размеры, цвета, события (onClick)

### 3. Добавление экранов и навигации

1. Откройте **Screen Manager**
2. Нажмите **«+»** — создайте новый экран (например, `SettingsScreen`)
3. В Editor у кнопки укажите событие `onClick → navigate → settings`

### 4. Переменные и логика

1. Откройте **State & Logic**
2. Нажмите **«+ Переменная»** — задайте имя, тип (Int, String, Boolean) и начальное значение
3. В Property Editor виджета привяжите текст к переменной: `Count: ${counter}`
4. Создайте событие `onIncrement` с действием `setState: counter = counter + 1`
5. У кнопки укажите `onClick: onIncrement`

### 5. Сборка и запуск

1. Нажмите **«▶ Собрать APK»** на экране Build
2. При первой сборке скачается toolchain (~130 MB) — это разовая операция
3. Следите за прогрессом в уведомлении. Время сборки: 5–15 минут
4. По завершению нажмите **«Установить»** — APK установится рядом

### 6. AI-ассистент

1. Откройте **AI Chat**
2. Напишите запрос: *«Сделай экран логина с двумя полями и кнопкой»*
3. AI сгенерирует JSON-патчи и покажет diff — что добавится/изменится
4. Нажмите **«Применить»** — экран появится в проекте
5. Соберите APK — готово

### 7. Экспорт проекта

1. **Settings → Экспорт проекта**
2. Выберите папку через системный picker (SAF)
3. Получите полноценный Gradle-проект, открывающийся в Android Studio

## Стек технологий

**IDE-приложение:**
- Kotlin 2.2.0, Jetpack Compose (Material3), Navigation Compose 2.9
- MVVM + StateFlow, AppContainer DI (Koin в M3+)
- Room, Ktor Client, Kotlinx Serialization, DataStore, Timber

**On-device toolchain:**
- kotlinc 2.2.0 (K2) через DexClassLoader
- Eclipse JDT Compiler (ecj) 3.40.0
- aapt2, d8/R8, apksigner, zipalign
- KotlinPoet для codegen
